    Execute(INonQueryCommand, string)

    Executes a non-query command.

    Declaration
    int Execute(INonQueryCommand command, string serverIp = "")
    Parameters
    Type Name Description
    INonQueryCommand command

    The command.
    string serverIp

    The server ip. It is used to specify the server ip to connect to. If not specified, the server ip will be read from the configuration file. If the server ip is specified, the server ip in connection string will be updated with the server ip. This parameter is useful when you want to connect to a different server based on the database cluster.
    Returns
    Type Description
    int

    The number of rows affected.
    Examples
    var command = new UpdateProductCommand();
var rowsAffected = repository.Execute(command);

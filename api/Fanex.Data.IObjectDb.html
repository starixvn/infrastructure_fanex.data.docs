    Interface IObjectDb

    Represents a object db.

    Namespace: Fanex.Data
    Assembly: Fanex.Data.dll
    Syntax
    public interface IObjectDb
    Remarks

    This interface inherits from IDisposable. Remember to dispose the object db after using it.

    Getting Started

    Installation

    Install the required NuGet packages using the .NET Core CLI:

    dotnet add package Fanex.Data
dotnet add package Fanex.Data.Repository
dotnet add package Fanex.Data.SqlServer

    Usage Guide

    1. Configure Stored Procedures in SpNames.xml

    Create an SpNames.xml file and add your stored procedure configurations. This file should be set to "Copy if newer" in its properties to ensure it's included in the build output.

    <Setting Key="QueryProducts" SpName="QueryProducts" DbName="FanexDataUnitTests">
</Setting>

    2. Configure Connection Strings in appsettings.json

    Add your database connection strings to the appsettings.json file.

     "FanexConnectionStrings": [
   {
     "Name": "FanexDataUnitTests",
     "ConnectionString": "Data Source=localhost;Initial Catalog=FanexDataTests;User ID=sa;Password=abczz",
     "ProviderName": "System.Data.SqlClient"
   }
 ]

    3. Register Fanex.Data in Startup.cs or Program.cs

    In your Startup.cs or Program.cs, register Fanex.Data in the ConfigureServices method.

    services.AddFanexSql(configuration, connectionStringSection: "FanexConnectionStrings");

    4. Define a Criteria Class

    Create a criteria class that inherits from CriteriaBase. This class will define the parameters for your stored procedure.

    public class QueryProductsCriteria : CriteriaBase
{
    public string GroupId { get; set; }

    public override string GetSettingKey()
        => "QueryProducts";

    public override bool IsValid()
        => !string.IsNullOrWhiteSpace(GroupId);
}

    5. Using DynamicRepository

    Instantiate DynamicRepository and use the Fetch method with your criteria object to retrieve data.

    var repository = new DynamicRepository();
var criteria = new QueryProductsCriteria{ GroupId = "123456" };
var products = repository.Fetch<Product>(criteria);

    6. Switching Stored Procedure Versions

    To switch to a different version of a stored procedure (e.g., for testing), simply update the SpName attribute in your SpNames.xml file.

    <Setting Key="QueryProducts" SpName="QueryProducts_xtest" DbName="FanexDataUnitTests">
</Setting>

    ObjectDb Examples

    Query Entity With Parameter Set Being An Anonymous Object

    Query a single entity using an anonymous object as parameter set.

    var parameterSet = new
{
    OrderId = orderId,
    TotalOrder = 0 // This is an output parameter
};

using var objectDb = ObjectDbFactory.CreateInstance(QueryingOrderByIdSettingKey);
var order = objectDb.QueryEntity<Order>(parameterSet);

Console.WriteLine($"ShipAddress: {order.ShipAddress}");
Console.WriteLine($"Total Orders: {parameterSet.TotalOrder}");

    Query Entity With Parameter Set Being A Hashtable

    Query Multiple With Parameter Set Being An Anonymous Object

    Query multiple result sets using an anonymous object as parameter set.

    DataSet Examples

    Read DataSet With Parameter Set Being An Anonymous Object

    Read data using DataSet with an anonymous object as parameter set.

    var parameterSet = new
{
    CustomerId = TestedCustomerId,
    PageIndex = 1,
    PageSize = 10,
    TotalOrders = 0 // This is an output parameter
};

using var objectDb = ObjectDbFactory.CreateInstance(QueryingOrdersByCustomerIdSettingKey);
using var dataSet = objectDb.ExecuteDataSet(parameterSet);
var dataTable = dataSet.Tables[0];
var orders = (from DataRow dataRow in dataTable.Rows select ReadOrder(dataRow)).ToList();
var totalOrders = Convert.ToInt32(parameterSet.TotalOrders);

Console.WriteLine($"Got {orders.Count} of {totalOrders} orders");
